# Agent notes

## ui-sdk

- Before using ui-sdk, follow the `ui-sdk` skill if it's installed, and read
  `node_modules/@ui-sdk/react/docs/llms.txt`.

- To build a new component, also search
  `node_modules/@ui-sdk/react/docs/core.md` by heading, and read
  `rendering.md` next to it.

## Agent-navigability comparison

- To run, extend, or report on the comparison between zeiss.com and this
  rebuild (`docs/agent-navigability.md`), follow the
  `agent-navigability-comparison` skill in `.agents/skills/`.
